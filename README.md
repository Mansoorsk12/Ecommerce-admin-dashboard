# Ecommerce Admin Dashboard

A React-based Ecommerce Admin Dashboard designed to provide a simple interface for managing and monitoring ecommerce business activities. It includes a login page and a dashboard displaying revenue, transactions, and product information.

## 🚀 Features

- **Login Page** – Simple login interface for accessing the dashboard.
- **Dashboard Overview** – View important ecommerce statistics.
- **Revenue Summary** – Display revenue-related information.
- **Transaction Details** – View sample transaction records.
- **Product Information** – Display product details.
- **Logout Functionality** – Log out and return to the login page.
- **Responsive Interface** – Clean and user-friendly dashboard layout.

## 🛠️ Technologies Used

- React.js
- JavaScript
- Vite
- HTML5
- CSS3
- Tailwind CSS

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/Mansoorsk12/Ecommerce-admin-dashboard.git
```

**2. Navigate to the project directory**

```bash
cd Ecommerce-admin-dashboard
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

```text
http://localhost:5173
```

## 🏗️ Build for Production

To create a production build, run:

```bash
npm run build
```
